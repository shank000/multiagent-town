# 对话连续性与语义审校验收

## 发布状态

第 2 项语义审校为候选实现，真实会话验收未通过，尚不满足正式研究启用条件。Windows `v0.1.1-preview.20260907` 是公开这些限制的协作测试版，供功能试用、故障复现与反馈；正式研究版本仍要求完整对话验收通过。独立验收使用内存数据库，现有实验的配置与持久化状态保持独立。工程测试通过代表链路行为符合测试约定，不代表台词真实或适合正式社会科学实验。

## 当前机制

- 生成请求包含说话者档案、对方公开身份、会话前文、当前场景和说话者的个人观察。内部规划、反思和关系摘要与可公开说出的事实分别处理。
- 台词先接受承接、重复、事实与格式规则检查，再由当前真实模型完成一次独立语义审校。审校核对事实依据、问答关系、身份指代、意图与完成状态及审计套话。
- 审校输出明确判定和简短依据。`accept` 与 `revise` 均须附带有效依据；缺字段、错误类型或超长内容按审校不可用处理。
- 每轮最多两次生成；每个通过规则检查的候选分别审校。兜底同样接受规则与语义检查，事件始终标注 `safe_fallback`，与模型原生台词分别统计。
- 实际通过审校的台词才发布给对方并进入正式消息。审校意见和被拒候选只属于诊断信息，不作为居民听到的话或观察记忆。
- 生成、重写与审校共用一轮执行预算和排队预算，默认分别为 90 秒和 240 秒。审校不可用或所有候选被拒时，本轮记录失败；候选不会作为成功发言发布。
- 审校沿用对话优先级及认知同步屏障。界面区分等待审校与正在审校，安全关闭等待在途审校结束并阻止后续重写。
- `dialogue-turn/v5` 的质量元数据包含 `dialogue-semantic/v1` 判定、候选类型、观察记忆 ID、上下文摘要哈希、实际模型、耗时和 token 数。`validated` 仅表示规则和模型审校均通过，**不是事实保证**。
- 省略对象的收信人追问使用会话前文解析；身份答案须有明确收信人记录。频率、时长、时刻和价格使用对应细节检查，数值支持中文数字、阿拉伯数字与常见等值时长表达。
- `eventEvidence` 专门承载个人观察与开场观察，动作完成和阅读经历依据来自此集合。人物背景、功能清单与传闻保留各自的信息边界。

三段会话合计 18 次生成、15 次审校；审校输入 9,194 token、输出 1,594 token，单次观测耗时约 0.89–1.68 秒。已发布的 9 句均带审校通过记录，但人工复核发现漏判，因此通过数量不能作为正确台词数量。

关键证据：

- 书店场景中，审校误拒普通告别“嗯，我明白你的意思了。今天先聊到这里吧”，并额外要求人物展示职业背景。角色风格不能成为每句发言必须满足的事实条件。
- 咖啡馆场景中，审校将香气比喻当作须有履约记录的事实。随后对“每天都这么准备吗”的兜底仅陈述桌上咖啡，未回答频率问题，此次拒绝有依据。
- 广场场景中，观察只记录找到收信人并核对姓名，审校仍放行“是沈屿家”。下一句“那孩子这几年都去外地了”同样缺少依据，却被解释为符合职业背景。审校模型也会生成错误的支持理由。

## 使用与数据边界

PowerShell，使用已部署的本地模型：

```powershell
$env:LLM_PROVIDER = 'ollama'
$env:OLLAMA_MODEL = 'qwen3:4b-instruct'
$env:OLLAMA_SMALL_MODEL = 'qwen3:4b-instruct'
$env:LLM_MAX_CONCURRENCY = '1'
pnpm test:dialogue:review
pnpm test:dialogue:real
```

8B 对照使用 `$env:OLLAMA_MODEL = 'qwen3:8b'` 与 `$env:OLLAMA_SMALL_MODEL = 'qwen3:8b'`。以下开关仅影响独立验收进程：

```powershell
pnpm test:dialogue:review --thinking
pnpm test:dialogue:review --transfer
```

固定样例输出校准与保留集合的漏放、误拒和不可用数量；任意判定不符预期即返回非零退出码。完整会话固定使用 `:memory:`，不读取或写入运行中工作空间，不启动 Web 服务。完整会话验收要求 4–6 句、正常结束、全部经过审校且无兜底，并始终要求人工语义复核。实际验收模型与本地实验共享推理硬件，会占用少量推理资源。

后台 `[dialogue-review]` 记录可按世界范围、会话 ID 和轮次关联。`contextDigest` 用于辨识审校输入，不提供哈希到原始上下文的还原能力。判定依据是模型的审校意见，不是新的世界事实。

## 启用条件与研究限制

当前 4B 与 8B 对照均不满足完整对话验收门。后续模型选择须同时考虑真实会话、审校迁移能力、硬件容量和耗时，额外模型下载或实验运行配置变更须获得用户确认。当前候选限于协作功能测试，不应作为正式实验版本启用。

复验须同时覆盖事实正确性、自然接话、拒绝率、会话正常完成率和总推理成本。小样本、提示词校准和非固定生成种子的结果不能用于估计长期错误率，也不能证明因果改善。

审校会改变哪些互动得以发生，可能对不同实验组施加不同筛选压力。正式研究应固定并报告审校模型、版本与预算，分别统计各处理组的生成拒绝率、语义拒绝率和缺失会话，避免将模型筛选效应解释成关系记忆的社会效应。
