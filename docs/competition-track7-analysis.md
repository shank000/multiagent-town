## 二、赛道 7 的评判重心（区别于其他赛道）

赛道 7 是「探索方向」，它的加分点不是「又跑了一个社会模拟」，而是**方法学与边界探索**：

- 智能体作为**社会参与者 / 模拟被试 / 研究辅助工具**的新用法；
- 人类与 AI 智能体共存社会中的新型互动关系、群体行为与社会规则；
- **大模型智能体 × 社会网络分析 / 主体建模 / 行为实验 / 因果推断**的有机结合；
- **如何评估智能体社会模拟的真实性、可靠性、可解释性与可重复性**（这是赛道 7 的招牌问题——多数参赛者会忽略它）。

**结论**：赛道 7 的制胜组合 = **一个可证伪的因果机制发现** + **一套可复现的智能体社会实验方法论**（含真实性/稳健性/可复现性诊断）。

## 三、我们的选题与定位

### 研究问题
**智能体能否访问「与特定伙伴的历史互动记忆」，是否把本来离散的互动变成历史依赖的伙伴选择，并随时间涌现出持久的关系结构？**

### 为什么这题适配赛道 7
1. 机制对象 = 智能体社会互动（社会参与者用法）；
2. 方法链 = 因果设计（记忆开/关随机化）× 社会网络分析（涌现网络结构）× 主体建模（LLM Agent）→ 直接踩中「网络分析×主体建模×行为实验×因果推断」；
3. 自带**可靠性/可复现性实验**（种子×模型×提示扰动）→ 正面回答「如何评估智能体社会模拟」；
4. 理论落点：社会嵌入性（Granovetter）、重复博弈中的合作与关系资本、关系记忆的认知基础——可对话社会学理论文献。

### 预实验证据（自研引擎，20 天 × 3 种子，mock LLM）
| 指标 | 记忆关/无礼 | 记忆关/馈礼 | 记忆开/无礼 | 记忆开/馈礼 |
|---|---:|---:|---:|---:|
| 有向同对重复率 | 0.222 | 0.222 | 0.553 | 0.608 |
| 伙伴多样性（7 日窗口） | 3.458 | 3.458 | 2.317 | 2.139 |
| 伙伴 HHI（7 日窗口） | 0.380 | 0.380 | 0.614 | 0.683 |
| 双 7 日矩阵持续性 | −0.043 | −0.043 | 0.561 | 0.593 |
| 枢纽集中度 | 0.253 | 0.253 | 0.340 | 0.370 |

表中数值为先在 seed 内汇总、再对 3 个 seed 取均值的本地机制正控。它支持“协议与测量对代码注入的历史依赖有响应”这一工程判断，不支持 LLM 历史可见性的因果结论或显著性声明。逐 seed 数据固定在 `docs/data/local-reference-pilot-20d-3seed.v1.json`。

## 四、正式实验设计（AgentSociety² 平台）

### 场景
自定义 `PartnerChoiceEnv` 与 observation-only `PartnerChoiceAgent` 共同完成「每日伙伴选择」：N 个 agent 在社交时段从等量候选集中选 1 名互动。主实验是历史 `none/full` × 馈礼 `off/on` 的完整 2×2；`recent_k=3` 作为稳健性扩展。所有条件经过相同 fresh completion、提示、解析、重试与 fallback 流程，历史处理只改变 observation 中可见的 dyadic history；处理标签仅留在研究者审计面。自研引擎的“代码评分 vs seeded uniform”只作为机制正控。

### 规模与预算
- N = 24 个智能体，60 天，每条件 5 个预定 seed；真实 LLM 的具体型号在在线容量标定后、查看正式结果前固定。
- 主矩阵 20 个运行、28,800 次选择；recent-3 扩展后共 30 个运行、43,200 次选择。调用预算以平台实测 token、失败率和互动轮数为准。

### 测量（平台 ReplayWriter 全程留痕）
1. 唯一确认性主要结局：第 31—60 天的有向同对重复率均值。
2. 次要网络结局：第 31—60 天的 7 日 HHI、伙伴多样性、加权入度 Freeman 枢纽集中度、聚类与机会校正互惠性；第 14—60 天的相邻非重叠双 7 日有向矩阵 Pearson 持续性。
3. 时间演化：展示完整日序列与预定后期窗口，不以观察到的拐点重定义窗口。
4. 稳健性诊断：recent-3 优先；容量允许时依次登记模型/温度、提示措辞和 length-matched masked-history placebo。报告逐 seed 效应与边界条件，不以次要分析替代主要结局。

### 统计推断
- treatment×seed 世界运行是独立重复单位；day、agent、dyad 是运行内重复测量。
- 每个 run 先按预定时间窗汇总；历史主效应对 gift 边际化，馈礼主效应对 history 边际化，交互使用 2×2 difference-in-differences。报告每个 seed 的配对差值、均值、中位数、范围与 leave-one-seed-out 范围，不把 agent-day 作为独立样本。
- 5 个配对的双侧精确符号置换最小 p 值为 0.0625，基础设计不能在 α=.05 下给出确认性拒绝。若容量允许，追加 seed 必须在查看正式结果前登记。
- 通过 validator 且 fallback≤5% 的 run 进入 ITT；排除 fallback 仅作敏感性分析；任何跳过轮次使整个 run 失效。

## 五、赛道 7 差异化打法（评审加分项）

1. **方法学贡献**：产出「关系记忆访问权」这一可复用机制变量 + 「智能体社会涌现结构的测量框架」（代码开源，含稳定性诊断流程）
2. **可复现性声明**：预注册式设计 + 全流程种子化 + Replay 数据导出脚本 → 评委一票否决项是「不可复现」
3. **拓展讨论**：记忆访问权对应真实社会制度隐喻（社交平台的关系可见性、组织内部的关系记忆系统）；AI 社会试验平台的「实验伦理与人类对照」讨论（人类被试的这类实验早已有——对比 30 年前的重复博弈研究）
4. **叙事**：从「LLM 小人聊出朋友」升级为「记忆机制决定社会结构的分岔——一个可干预的涌现机制」
